# cssTestimonialCards
This is a CSS practice project proposed by the roadmap.sh community. Its purpose is to create a basic HTML and CSS static website structure with testimonial cards.

## Instructions to run
As this is a simple HTML/CSS project, in order to run it you can just download it and/or open the HTML file with your preferred browser and check the applied styles.
